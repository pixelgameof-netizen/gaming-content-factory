# Pixel Game Impact — guía visual de producción

## Objetivo

Crear Shorts que detengan el desplazamiento y conviertan el interés inicial en una razón para volver al canal. El estilo debe ser enérgico, reconocible y editorial; no una sucesión de plantillas llamativas ni un diseño minimalista que se pierda en el feed.

## Sistema visual

- **Gameplay primero:** el clip del juego domina la composición. El fondo desenfocado solo rellena el formato vertical; nunca sustituye ni simula gameplay.
- **Color:** contraste ligeramente elevado y saturación moderada. Acento lima Pixel Game (#B7F36B), blanco cálido y grafito. No usar neón en todas las superficies.
- **Gancho:** una sola idea clara en los primeros 1–2 segundos, con título grande y una frase secundaria breve. No repetir el título durante el resto del vídeo.
- **Ritmo:** cortes y transiciones discretas; reservar zooms o golpes de sonido para momentos con significado, no aplicarlos a cada plano.
- **Capítulos:** número y etiqueta en una franja compacta bajo el gameplay. Una jerarquía tipográfica, sin tarjetas gigantes ni barras de progreso repetitivas.
- **Subtítulos:** blancos, gruesos, legibles y en zona segura; dos líneas como máximo. El resaltado palabra por palabra requiere subtítulos con tiempos a nivel de palabra y no se debe fingir con un SRT por frases.
- **Cierre:** una pregunta específica que invite a comentar y una invitación secundaria a seguir Pixel Game para la próxima historia. No añadir una pantalla final larga que haga abandonar el Short antes del final.

## Fórmula editorial para suscriptores

1. **Curiosidad concreta:** pregunta, dato o contraste visual con promesa clara.
2. **Progresión:** 2–4 ideas breves que cumplen esa promesa, cada una con imagen relevante.
3. **Payoff:** una respuesta o revelación que justifique haber visto hasta el final.
4. **Puente de serie:** pregunta sobre el siguiente episodio y una invitación breve a seguir el canal.

La invitación a suscribirse no reemplaza el valor del vídeo. Cada Short debe funcionar por sí solo y, a la vez, dejar una continuación natural.


## Cómo evaluar el resultado

No aceptar un cambio visual solo porque parezca más llamativo. Comparar con la versión anterior en:
- Visualizaciones interesadas frente a deslizamientos.
- Retención en los primeros segundos y porcentaje medio visto.
- Suscriptores atribuidos al Short.
- Comentarios y espectadores recurrentes.

El estilo se ajustará a resultados reales, no a una promesa de viralidad.
